# 当前能力与支持边界

源码 **0.4.0.dev8，开发预览**。原生资源配置当前覆盖 Manta 1.1 Hotfix Build **26482553** 的限定范围；启动器配置包括 **2026.13**。精确文件身份见 [Manta 兼容性](MANTA_COMPATIBILITY.md)，实际机器以 `doctor.readiness`、`capabilities.current_environment` 和 `native-status.available_operations` 为准。

**版本敏感：游戏、编辑器、启动器或SDK更新，包括小型热修复，都可能需要二次适配。** 已审核某一哈希或资源操作，不代表同名版本、其他操作、所有Mod或实际玩法均兼容。未知配置保持拒绝，不能直接换哈希沿用旧偏移。

| 需求 | 当前能力 | 主要边界 |
| --- | --- | --- |
| R01 入口 | 独立Skill/CLI、分页导航和本机就绪诊断 | 就绪不是内容或玩法验收 |
| R02 维护 | 字段恢复、三方迁移、原子暂存、依赖审查、限定ACP准备/合并 | 冲突、不透明改写、原生诊断保持待审；不保证所有作品 |
| R03 创作 | 原生空项目、审核类的构造/标量与收入编辑、指定内嵌属性 | 完整魔典与复杂字段/规则、任意类创建未完成 |
| R04 素材 | 静态外壳/成员与历史受限流程 | 当前Manta原生素材、GPU/空间语义及完整动画未适配 |
| R05 地图 | 静态外壳/网格与历史受限编辑 | 当前原生地图未适配；完整创建及世界登记未完成 |
| R06 构建 | 按操作授权、独立读回、冻结证据与发布门槛 | 默认省略、准备差异和诊断不能自动清除 |
| R07 安装 | 同步/回滚、播放集事务及应用/schema/迁移配对 | 官方GUI重启、最终启用与回滚须在对应环境核对 |
| R08 工坊 | 预检、授权提交、未知结果恢复和下载核对 | 源码发布不授权Steam提交；传输不证明玩法 |
| R09 分发 | MIT、双语README、合成回归、可校验分发与独立运行 | 原始本机调试记录、私有案例及数据库不分发 |
| R10 调查 | 中文/文本键/ID/Tag定位、引用、审核效果解释及快照 | 部分枚举、复杂链、最终标签选择与多层提示未完成 |

当前Manta配置开放11项资源操作；素材、地图和编辑器桥接仍按未审核范围拒绝。结构比较、原生宿主合法性、最终合并和实际玩法分别报告。详细版本流程见[版本工作流](../references/game-version-workflows.md)。

本项目是Skill/CLI，没有MCP服务。功能目标见[需求](REQUIREMENTS.md)，后续工作见[路线](ROADMAP.md)。不按测试数或命令数推算总体完成率。
