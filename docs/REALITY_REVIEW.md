# 能力与证据的解释

以[当前状态](STATUS.md)和本机就绪信息为准。源码可用、格式可读、原生读回、最终包应用、真实玩法与工坊传输是不同范围。

- 合成回归证明其覆盖的边界、计划、比较、保留和失败处理；不证明真实引擎或UI。
- 原生读回须核对完整数据。构造默认值不能推广为所有加载路径的省略语义；只对对应版本/类/字段采用已审核规则。
- 原版对照能帮助归因，但原版同样产生诊断并不证明该诊断无害。出现次数与去重类别分别保留。
- 安装或上传一致不证明游戏已挂载、效果已执行、存档或多人兼容。开局列表声明也不证明最终授予或实际二级提示。
- 素材的CPU/字节一致不能代替空间、骨架、GPU、渲染或玩法。地图坐标可解码不证明合法部署与寻路。

尚未完成的广度包括复杂效果/标签选择、最终提示、更多空间和动画语义、完整地图与任意内容创作。不要用较多底层接口或测试代替R01–R10的用户结果。

公开文档保留脱敏经验与可执行流程；原始本机调试记录和私有案例不进入公开仓库或安装包。清理分发资料不改变对应能力仍须由执行者实测的事实。
