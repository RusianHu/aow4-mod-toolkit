# 多机部署与分发

## 安装与版本

按 [README](../README.md)直接克隆到项目 `<Mod工作区>/.agents/skills/aow4-mod-audit`。该实体目录同时是自动发现的Skill和独立Git开发仓库；开发、测试、提交及更新使用同一份源码。保留根目录SKILL.md、agents、scripts、references等相对结构，不只复制一个SKILL.md。外层项目应忽略这个独立仓库目录，避免重复纳入版本管理。

GitHub公开仓库名称为`RusianHu/aow4-mod-toolkit`；Skill标识和上述安装目录仍是`aow4-mod-audit`。按README中的显式目标目录克隆，避免把仓库名称当成需要同步改动的Skill标识。

其他电脑可克隆到相同相对位置，再检出约定tag或开发分支。用户级 `~/.agents/skills`是明确需要跨项目共享时的另一种选择；避免多个同名副本。

每台电脑使用自己的Python环境和Steam/Paradox安装。先执行 `doctor`、`native-status`，再按任务执行 `game-version` 或启动器inspect。当前只验证Windows x64/Python3.10及列明的原生/启动器配置；其他机器仍需验收，不能绕过DLL哈希限制。

更新前在Skill仓库检查 `git status --short`；干净分发副本可用 `git switch main`、`git pull --ff-only`。有本地改动时先保存到自己的开发分支，不用reset覆盖。需要固定基线时检出已验证tag；Git更新后按需要重新安装Python依赖。压缩包安装者先保留旧目录，再安装新版，不将新旧文件混合。

公开基线的历史经过隐私清理。若持有清理前的旧克隆，保留自己的必要修改后重新克隆，不将旧分支或tag合回新基线。原始本机证据应留在仓库外的私有位置。

## 共享与本地状态

| 可以同步 | 必须本地创建或重新确认 |
| --- | --- |
| 本仓库源码、参考文档、测试、版本tag | Python环境、索引、native缓存、临时导出 |
| Mod作者源文件与相应Git提交 | 本机路径、游戏/DLC文件、Steam登录与权限 |
| 用于审阅的只读报告/冻结材料 | 修改计划、安装/回滚收据、启动器数据库与配置 |

把Mod源码、项目构建目录和Skill目录分开。示例工作区 `D:/AoW4Projects/MyMod`：从这个目录运行Skill的绝对入口，`.aow4mod/`、项目stage和release均属于该工作区，不要放在Skill仓库内。

旧计划和收据绑定完整路径、源哈希、应用版本和本机状态，不能直接搬到新机apply。一般从Mod源重新index/assess/plan/build/freeze。冻结材料可用于审阅，但其中的绝对路径不代表跨机可直接提交；遇到已有未知结果的上传尝试，保留原机收据并按reconcile恢复，不能重新创建或盲目重传。

同一工坊条目一次由一台机器提交，其余机器负责源码/审阅；当前没有跨机分布式发布锁。发布前重新核对账号、条目、当前候选和远端身份。Git推送源码不是Steam提交授权。

## 本机依赖

核心CLI无需安装游戏即可读取指定ACP/RPK和查看帮助/能力；游戏相关命令需本机合法安装。游戏路径优先自动发现，必要时使用 `--game` 或进程级 `AOW4_GAME_DIR`。不把原电脑的C盘绝对路径写成全局默认。

原生配置区分Witch历史范围与Manta的部分资源支持，见[当前兼容性](MANTA_COMPATIBILITY.md)。实际DLL需匹配已记录哈希，并在 `native-status.available_operations` 中包含所需操作；同BuildID也不能替代文件哈希检查。游戏/工具更新后重新提取schema并更新原版索引，旧计划须重新生成。启动器支持范围按其应用哈希与数据库迁移集合判断，不自动给其他电脑换版本。

Node.js22+仅用于需要原生WebSocket的启动器界面验收脚本；普通CLI无需Node。SteamCMD、DirectXTex、DXC等可选工具按reference准备到独立工具目录，不随Git/ZIP复制官方二进制，也不复制Steam登录配置。网络受限时仅按该电脑环境配置代理；原工作区127.0.0.1:10808不是其他电脑的必需设置。

## 示例与证据边界

`prepare_*`配方是指定模板/类型的受限作者样例，不是任意内容生成器。新项目生成自己的包身份，已有工坊作品显式配置自己的条目和作者，不使用维护者私有案例的固定身份。

公开资料只保留脱敏经验与可重现流程。原始调试记录、数据库、素材、收据和计划保留在执行者自己的私有工作区，不是Skill安装依赖，也不随Git/ZIP分发。有效回滚或未知上传结果相关证据不能当作普通缓存清空。
