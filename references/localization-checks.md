# 文本、语言装载与二级提示

只读取相关小节。词典/文本键定位见[内容调查](content-research-workflows.md)，写入命令见[作者流程](authoring-workflows.md)。静态文本检查与实际显示分开验收。

## 词典与加载顺序

- 先沿 RPK 的 MO 依赖找到实际文本键和选中的词典。不同语言目录里的同名 MO 曾产生命名空间冲突；目录名本身不保证自动切换语言。
- 区分 ZIP 的语言后缀聚合与松散 ACP 的装载路径，不能推广同一规则。只需中文时可用单包默认 MO；合并翻译后撤除不再需要的旧翻译包，避免后加载覆盖。
- 多语言验证须复现真实启动中“应用语言设置—导入包”的顺序。独立引擎预设语言后加载成功，不证明游戏应用语言后会重建已导入的 Mod 词典。
- ZIP 装载会产生解压的 ACP/RPK、词典和 `lastupdated` 缓存。保留发布 ZIP，升级时按安装流程替换目录，避免新 ZIP 与旧缓存混用；不把生成缓存当新的维护源。

## 概念链接与格式

- 已有游戏概念优先引用原版 `Hyperlink`；同步 MO 占位符与完整 `LocaLink` 解析键，并核对资源实际 `DataStoreTag`。字符串相似或一级文字出现，不证明悬停链接可展开。
- 使用该界面实际支持的富文本语法。法术说明中的 `<br></br>` 曾直接显示为文字，改为原生 `[br/]` 后正常；不要把 HTML 通用语法当游戏语法。
- 区分字段为空、使用原生自动描述和引用了错误键；不因空描述字段就填入重复说明。实际提示入口仍要验证。

## 按入口核对说明

- 社会特质的“初始加成”来自启动属性 `DescriptionLink`，被动效果用 `EffectDescriptionLinks`；`LoreLink` 留作背景，避免自动效果区重复。
- 单位被动、技能与战斗提示分别追踪属性组、能力属性和判定修正的链接；只改 `ScreenDescriptionLink` 或共享文本可能漏掉另一入口。
- 复用修正时读取实际 `Display in Unit Panel`、`Display Type` 等显示字段。列表隐藏不等于技能提示隐藏，也不能由提示缺失直接推断存档未授予属性。
- 内容文字、语言切换、二级提示分别记录观察；手工注册词典/提高优先级的阳性测试不替代真实启动顺序。未执行的界面检查按未验证报告，遵守用户的实测安排。
